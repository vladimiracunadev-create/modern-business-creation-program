# Historial de licenciamiento

Este documento registra el cambio de modelo sin retirar permisos ya concedidos.

## Etapa MIT original

El repositorio se publicó inicialmente con una licencia MIT que cubría el
código, la documentación y el material original. Esa declaración apareció en
el commit `7563f04df6ae6850b68f66914b0ce6c87a1d4dd1`, de 2026-08-13.

La última revisión publicada íntegramente bajo ese modelo fue:

- commit: `c8a17b9a5d4bf56bf5b59660ca216f3224bb82d4`;
- fecha: 2026-08-19;
- autor y titular identificado: Vladimir Acuña;
- cuenta: `vladimiracunadev-create`.

Las licencias MIT otorgadas sobre esas revisiones son irrevocables conforme a
sus propios términos. Quien obtuvo una versión histórica puede seguir usando,
modificando, distribuyendo, sublicenciando o vendiendo esa versión bajo MIT. El
nuevo modelo tampoco elimina los derechos sobre derivados basados únicamente
en material recibido válidamente bajo MIT.

## Modelo vigente desde la transición

Desde el commit que incorpora este documento, el repositorio separa:

| Material | Licencia o régimen |
|---|---|
| Código de software | MIT, según [`LICENSE`](../LICENSE) |
| Contenido educativo original | CC BY-NC-SA 4.0, según [`LICENSE-CONTENT.md`](../LICENSE-CONTENT.md) |
| Plantillas y metodologías originales | CC BY-NC-SA 4.0; no se identificaron excepciones reservadas en la auditoría de transición |
| Normas, formularios y publicaciones oficiales | Régimen jurídico y atribución de la fuente original |
| Obras y componentes de terceros | Licencia o permiso de cada titular, según [`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md) |
| Nombres y marcas | Sin concesión de derechos de marca; véase [`TRADEMARKS.md`](../TRADEMARKS.md) |

El contenido histórico visible en la rama actual puede coincidir con una versión
que antes estuvo disponible bajo MIT. Esta transición controla cómo el titular
ofrece la rama y las versiones futuras; no borra la licencia de las copias
históricas.
