# Matriz de permisos: empresa legalmente constituida ≠ negocio autorizado para operar

## Capa general

1. Constitución y RUT.
2. Inicio de actividades.
3. Domicilio y compatibilidad territorial.
4. Patente municipal.
5. Permisos sectoriales.
6. Seguridad y salud laboral.
7. Condiciones del inmueble.
8. Permisos ambientales cuando correspondan.

## Matriz por actividad

| Actividad | Autoridades a revisar | Ejemplos de habilitación |
|---|---|---|
| Oficina/servicios | Municipalidad, SII | patente, domicilio |
| Alimentos | Municipalidad, SEREMI Salud | autorización sanitaria, DS 977 |
| Restaurante/dark kitchen | Municipalidad, Salud, DOM | patente, sanitario, inmueble |
| Construcción | DOM, MINVU, especialidades | permisos LGUC/OGUC |
| Electricidad/combustibles | SEC | instaladores/declaraciones |
| Telecom | SUBTEL | concesión/permiso si aplica |
| Turismo | SERNATUR + sectoriales | registro/estándares según servicio |
| Salud | SEREMI/Superintendencia/ISP según actividad | autorización y dirección técnica |
| OTEC | SENCE y sistema de calidad/requisitos | registro/acreditación |
| Residuos/reciclaje | Salud, SMA/SEA, municipio | autorizaciones según residuo/proyecto |
| Agro/alimentos primarios | SAG y autoridad sanitaria | registros/permisos |
| Transporte | MTT/municipio/sector | permisos vehiculares/operacionales |
| Fintech | CMF, UAF, BCCh según servicio | RPSF/autorización/AML |
| Mercado de valores | CMF | registros/autorizaciones |
| Venta al Estado | ChileCompra | Mercado Público y bases |
| Importación/exportación | Aduanas, SAG/ISP/otros según producto | destinación y vistos buenos |

## Patente municipal

No asumir que el SII resuelve la patente. La municipalidad evalúa antecedentes y actividad.
Revisar la ordenanza y requisitos de la comuna concreta.

## Uso de suelo

Antes de arrendar/comprar un local:

1. verificar uso permitido;
2. revisar recepción final/destino;
3. confirmar obras necesarias;
4. condicionar contrato a obtención de permisos cuando sea posible.

## Alimentos

ChileAtiende indica que instalaciones que producen, elaboran, preservan, envasan,
almacenan, distribuyen o expenden alimentos/aditivos requieren autorización sanitaria.
Fuente:
https://www.chileatiende.gob.cl/fichas/172-autorizacion-sanitaria-de-alimentos

## Gate de apertura

No abrir hasta que la matriz muestre:

- permiso;
- autoridad;
- responsable;
- fecha solicitud;
- vigencia;
- condición;
- evidencia;
- obligación de renovación.
