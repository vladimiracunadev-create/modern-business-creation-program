> [!IMPORTANT]
> Este repositorio es **material educativo y de ingeniería empresarial**. No reemplaza asesoría
> legal, tributaria, contable, laboral, sanitaria, financiera ni regulatoria para un caso concreto.
> La legislación cambia y una misma actividad puede tener exigencias municipales o sectoriales
> distintas. Antes de ejecutar un trámite hay que **verificar la fuente oficial vigente** y, cuando
> corresponda, validar con el profesional competente.

## 🎯 Qué es esto

Un currículo secuencial de **336 clases en 24 partes** que recorre el ciclo completo de una empresa:

`descubrimiento → validación → modelo → estrategia → sociedad → constitución → SII → contabilidad → caja → contratos → consumidor y datos → personas → operación → ventas → tecnología → financiamiento → permisos → comercio exterior → compliance → escalamiento → crisis → salida`

El principio que ordena todo el material:

> Una empresa no es el certificado de constitución. Es un sistema que convierte capital, personas,
> activos, conocimiento, tecnología y permisos en valor para clientes, mientras cumple obligaciones
> legales, tributarias, laborales, financieras y operativas.

No se trata de "memorizar la ley". Se trata de saber **qué decisión dispara qué obligación, quién es
responsable y qué evidencia debe quedar**.

## 📦 Contrato de una clase

Cada clase es una carpeta con un `README.md` autocontenido que siempre incluye, en este orden:

```text
# Clase NNN — Título
├── Cabecera            ← estado de evidencia, decisión que habilita y entregable
├── 🎯 Propósito         ← por qué existe la clase, en prosa
├── 📚 Resultados        ← 5 capacidades verificables
├── 🧩 Conceptos         ← 4 definiciones operacionales propias de la clase
├── 🗺️ Diagrama          ← flujo de razonamiento mermaid, construido con sus conceptos
├── 📖 Desarrollo        ← el fondo · cómo se traduce en la práctica · marco y actores
├── 🧪 Taller guiado     ← 7 líneas de negocio con su carga regulatoria + secuencia
│   └── 📦 Entregable    ← artefacto concreto y revisable
├── 🏆 Reto verificable
├── ✅ Criterio de aceptación  ← específico de la clase, no genérico
├── ⚠️ Errores frecuentes      ← propios de la clase + característicos de la parte
├── 🇨🇱 Checklist Chile
├── ❓ Preguntas de comprobación ← 3, para contrastar contra el propio negocio
└── 🔗 Fuentes oficiales        ← con qué contiene cada una y cómo leerla
```

Cada parte añade además narrativa de contexto, mapa visual, glosario propio, conexiones con las
demás partes y pauta bibliográfica.

El contenido **no se escribe a mano en los README**: se genera desde
[`manifests/`](manifests/) con [`scripts/generar_clases.py`](scripts/generar_clases.py), y el CI
falla si un README quedó desincronizado respecto de su manifiesto.

## 🧭 Ruta maestra

1. Descubrir un problema real.
2. Validar cliente, demanda y disposición a pagar.
3. Diseñar modelo de negocio y estrategia.
4. Elegir forma societaria y reglas entre socios.
5. Constituir la persona jurídica.
6. Obtener RUT e iniciar actividades en SII.
7. Seleccionar régimen tributario y habilitar DTE.
8. Resolver domicilio, patente municipal y permisos sectoriales.
9. Abrir infraestructura financiera y contable.
10. Diseñar contratos, protección de datos, propiedad intelectual y compliance.
11. Contratar personas y cumplir normativa laboral y de seguridad y salud.
12. Operar compras, inventario, calidad, ventas y postventa.
13. Controlar caja, impuestos, riesgos, seguridad y métricas.
14. Financiar, exportar y escalar.
15. Prepararse para crisis, reorganización, venta, sucesión o cierre.

## 📅 Contexto normativo 2026

El programa está calibrado a la realidad chilena vigente a la **fecha base 07-08-2026**:

- **Ley 21.719** de protección de datos personales: vigencia el **1 de diciembre de 2026**; la parte 11 trabaja la transición desde la Ley 19.628.
- **Ley 21.561**: jornada ordinaria de **42 horas semanales desde el 26 de abril de 2026**, camino a 40 horas en 2028.
- **Ley 21.643 (Ley Karin)**: protocolo, canal de denuncias e investigación obligatorios.
- **Ley 21.595** de delitos económicos: catálogo ampliado de responsabilidad penal de la persona jurídica.
- **Ley 21.713** de cumplimiento tributario: facultades reforzadas y exigencia de razón de negocios documentada.
- **Ley 21.521 Fintec** y Sistema de Finanzas Abiertas de la CMF.
- **Ley 21.663** Marco de Ciberseguridad y la ANCI.

Seguimiento en [`docs/17_2026_WATCHLIST.md`](docs/17_2026_WATCHLIST.md).

## 🔧 Trabajar con el repositorio

```bash
pip install -r requirements.txt             # solo necesario para compilar el PDF

python scripts/generar_clases.py            # regenera currículo y glosario desde los manifiestos
python scripts/generar_clases.py --check    # falla si hay READMEs desincronizados
python scripts/validar_estructura.py        # estructura, secciones, diagramas y enlaces
python scripts/validar_encoding.py          # UTF-8 sin BOM y sin mojibake
python scripts/generar_manual.py --partes   # manual integral + 24 PDF por parte
python scripts/generar_sitio.py             # sitio HTML en site/ (copia los PDF)
python -m unittest discover -s tests -v     # pruebas estructurales
```

Para editar contenido de una clase se modifica su entrada en
`manifests/classes/parts-NN-NN.json` y se vuelve a ejecutar el generador. Editar el `README.md`
directamente hace fallar el CI, a propósito: la fuente de verdad es el manifiesto.

## ⚖️ Límites

- Material educativo; no constituye asesoría profesional para un caso concreto.
- La normativa cambia: los datos marcados como `DINAMICO` deben revalidarse en la fuente antes de usarse.
- Una misma actividad puede tener exigencias distintas según comuna, sector y escala.
- Los casos y ejemplos usan datos ficticios; no se incluyen RUT, nombres ni antecedentes reales.
